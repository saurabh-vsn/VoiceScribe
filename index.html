Pipeline

How it works — 4 steps

01 — INPUT
🎙️
Voice Capture
Web Speech API converts spoken words to text in real-time via the browser microphone.
02 — PROCESS
⚙️
Vector Engine
Custom JS converts text to Hershey font vector paths — single-stroke coordinates for each character.
03 — TRANSMIT
📡
Web Serial API
G-code streams directly from Chrome to the Arduino USB port — no drivers, no middleware.
04 — WRITE
✍️
Pen on Paper
NEMA 17 steppers move X/Y axes while SG90 servo lifts the pen between characters.
